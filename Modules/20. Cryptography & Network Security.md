### Encoding
#### Base64
```bash
Base64 is not encryption, it is an encoding method that converts binary data into readable text using A–Z, a–z, 0–9, +, /.

# encodding text to base64
echo "hello" | base64

# Decoding Base64 to text
echo "aGVsbG8=" | base64 -d
echo "aGVsbG8=" | base64 --decode

base64 Sniff.txt > encoded.txt
base64 -d Sniff.txt > secret.txt
```

```bash
| Encoding     | Tool/Command                      | When to Use                                           |
|--------------|-----------------------------------|-------------------------------------------------------|
| Base64       | `base64`, Base64 Decoder, CyberChef | Strings ending with `=` or `==`                       |
| Base32       | `base32`, CyberChef               | Encoded strings using `A-Z` and `2-7`                 |
| Hexadecimal  | `xxd`, `xxd -r -p`, CyberChef     | Hex strings like `48656c6c6f`                         |
| URL Encoding | CyberChef, URL Decoder            | Encoded URLs containing `%20`, `%2F`, `%3A`, etc.    |
| Binary       | CyberChef                         | Binary strings like `01001000 01100101...`           |
| ASCII        | `xxd`, CyberChef                  | Convert decimal/hex values to readable text          |
| ROT13        | `tr`, CyberChef                   | Simple Caesar cipher (ROT13)                         |
| Unicode      | CyberChef                         | Unicode escape sequences like `\u0048\u0065...`      |
| Morse Code   | CyberChef                         | Morse code like `.... . .-.. .-.. ---`               |
```
